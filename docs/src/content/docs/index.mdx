## Features at a Glance

<CardGrid>
  <Card title="Dual Backend Architecture">
    <Monitor size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    Runs nested (via <code>winit</code>) or on real hardware (TTY / DRM / KMS / libseat), sharing one rendering pipeline.
  </Card>
  <Card title="Windows 10-Style Desktop">
    <AppWindow size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    Taskbar, Start menu with search, Action Center &amp; system tray, 10 virtual desktops, Task View, and edge/corner snapping.
  </Card>
  <Card title="CPU-Painted UI">
    <Cpu size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    Taskbar, menus, and titlebars rendered on CPU via <code>canvas.rs</code> and cached by key for fast GPU compositing.
  </Card>
  <Card title="XWayland + Gaming">
    <Gamepad2 size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    Full GPU acceleration via <code>linux-dmabuf</code> with explicit sync, relative pointer + pointer constraints, and optional direct scanout.
  </Card>
  <Card title="Six Built-in Apps">
    <Box size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    Settings, PowerSlop, File Exploder, Task Mangler, Snip &amp; Sketchy, and About VIDE-DE — all registered as <code>.desktop</code> entries.
  </Card>
  <Card title="StatusNotifierItem & Tray">
    <Radio size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    App tray icons via D-Bus (SNI watcher + host), plus built-in PipeWire volume and brightness flyouts.
  </Card>
  <Card title="Layer Shell Desktop">
    <Layers size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    Separate <code>vide-desktop</code> process on <code>wlr-layer-shell</code>: 6 wallpapers, <code>~/Desktop</code> icons, Recycle Bin, and context menu.
  </Card>
  <Card title="Control Socket & IPC">
    <Terminal size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    Plain-text Unix socket (<code>$VIDE_IPC</code>) for screenshots, snipping, clipboard PNGs, window control, and gated test input.
  </Card>
  <Card title="Health & Freeze Diagnostics">
    <HeartPulse size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    5s <code>xdg</code> client ping watchdog (<code>(Not responding)</code> titlebars), 3s main-loop &amp; 1.5s TTY page-flip watchdogs, and protocol error logging.
  </Card>
  <Card title="Privacy & App Permissions">
    <ShieldCheck size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    Settings <strong>Privacy</strong> page backed by the portal permission store for camera, mic, notifications, location, and screen-sharing revokes.
  </Card>
  <Card title="Live TTY Modes & Controls">
    <Sliders size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    Live <code>display_mode</code> and <code>display_scale</code> switching in TTY mode, plus Touchpad, multi-layout XKB Keyboard, 24h clock, and toasts.
  </Card>
  <Card title="Safe Nested Testing & Popups">
    <TestTube2 size={18} style="display:inline;vertical-align:text-bottom;margin-right:6px;" />
    <code>scripts/nested-test.sh</code> runs isolated sessions with <code>VIBE_TEST_INPUT=1</code> injection, plus geometry-accurate popup placement and focus.
  </Card>
</CardGrid>

## Get Started

```bash
# Build (nested mode)
cargo build --release --workspace

# Run nested (inside current desktop)
cargo run --release -- --nested

# Run on real hardware (from TTY)
dbus-run-session -- ./target/release/vibe-comp --tty
```
