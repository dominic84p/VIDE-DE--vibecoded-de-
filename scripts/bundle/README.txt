VIDE-DE, prebuilt
=================

For Linux Mint 22, Ubuntu 24.04 and newer, on x86_64. No compiling needed.

Install
  1. Unpack this folder anywhere (your Downloads is fine).
  2. Double-click "Install VIDE-DE".
     If the file manager asks whether to trust it, choose "Mark as Trusted" / "Launch".
     A terminal opens and asks for your password.
  3. Log out. On the login screen, click the session icon, pick VIDE-DE, and log in.

  Or from a terminal in this folder:  ./install.sh

Back to your usual desktop
  Log out and pick your old session (Cinnamon, etc.) on the login screen.

Uninstall
  ./uninstall.sh   (your settings in ~/.config/vide-de stay)

Something broke?
  The log of the last session is ~/vibe.log (the one before that: ~/vibe.log.old).
  Send it along with what you were doing.

Keys
  Super                  Start
  Super+E                File Exploder
  Super+Shift+P          Pin a window on top
  Ctrl+Shift+Esc         Task Mangler
  Super+Shift+S          Snip a screenshot
  Ctrl+Alt+Backspace     Leave VIDE-DE right away
